# 0002. Весь обмен с Толком — за интерфейсом ITalkGateway

**Статус:** Принято · 2026-09-04

## Контекст

До финала хакатона (этап 6) у нас нет доступа к внутренним API Толка.
Разрабатывать при этом надо так, будто он есть.

## Решение

Любой код, обращающийся к Толку — пользователи, комнаты встреч, саммари,
артефакты — живёт за единственным интерфейсом `ITalkGateway`. На этапах 3–5
работает реализация поверх mock-сервиса, на этапе 6 подменяется реальной.

Аналогично на фронте: цвета берутся только из `var(--tk-*)`, чтобы замена
на дизайн-систему Толка сводилась к правке одного файла токенов.

## Почему

Если общение с Толком расползётся по коду, интеграция на этапе 6 превратится
в переписывание проекта под дедлайн. Одна граница — одна точка замены.

## Последствия

Небольшой оверхед на маппинг между моделью Толка и нашей — сознательная плата
за то, что этап 6 остаётся выполнимым.
